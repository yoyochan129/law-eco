标签编辑设置

本站是纯静态网页，要让"编辑标签"的修改真正保存下来，需要一个能写入 GitHub 仓库(yoyochan129/law-eco)的 Personal Access Token。 Token 只保存在你这台设备的浏览器本地存储里，只会发送给 api.github.com，不会经过其他任何服务器。

  1. 访问 GitHub → Settings → Developer settings → Fine-grained tokens
  2. 新建token，Repository access 选择只授权 law-eco 这一个仓库
  3. Permissions 里把 Contents 设为 Read and write，其余保持默认
  4. 生成后粘贴到下面，点保存
